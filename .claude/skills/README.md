# Skills installés pour ce projet

Ces skills sont versionnés dans le repo pour qu'ils soient disponibles partout (laptop, web, iPhone) — Claude les charge automatiquement à chaque session lancée dans ce dossier.

## Skills design (depuis `nextlevelbuilder/ui-ux-pro-max-skill`, MIT)

- **`ui-ux-pro-max/`** — Intelligence UI/UX (50+ styles, 161 palettes, 57 paires de fontes, 99 guidelines UX)
- **`design/`** — Design unifié : logo, identité visuelle, mockups, slides, banners, icônes, photos sociales
- **`design-system/`** — Tokens (primitive → semantic → component), specs composants
- **`brand/`** — Voix de marque, identité, messaging frameworks
- **`ui-styling/`** — shadcn/ui + Tailwind CSS + canvas-based visual design
- **`banner-design/`** — Bannières social, ads, web, print (multi-art-direction)
- **`slides/`** — Présentations HTML stratégiques avec Chart.js

## Skill animations (depuis `199-biotechnologies/motion-dev-animations-skill`, MIT)

- **`motion-dev-animations/`** — Animations Motion.dev 120fps (React, Next.js, Svelte, Astro), spring physics, scroll, gestures, parallax
